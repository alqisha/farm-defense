# 🚀 Способы Запуска Игры в Telegram

Telegram требует, чтобы игра была на **HTTPS** (защищенном соединении). Просто `localhost` не сработает.
Вот два бесплатных способа, как это обойти:

---

## Вариант 1: С Ноутбука (Мгновенно) ⚡️
Идеально для тестов. Игра работает, пока включен ваш ноутбук и запущен терминал.

1.  **Запустите игру** в одном терминале:
    ```bash
    npm run dev
    ```
    (Убедитесь, что она работает на `http://localhost:5173`)

2.  **Создайте Туннель** (превращает localhost в HTTPS ссылку).
    Откройте **второй** терминал и напишите:
    ```bash
    npx localtunnel --port 5173
    ```
    *Если спросит подтверждение установки, нажмите `y`.*

3.  Вам выдадут ссылку, например: `https://slimy-dog-42.loca.lt`.
    **ЭТО и есть ваша Web App URL.**

4.  **Важный нюанс LocalTunnel**:
    При первом открытии этой ссылки в браузере (или в Телеграме) он может попросить ввести пароль IP. 
    *Чтобы этого избежать, можно использовать альтернативу `ngrok`, но там нужна регистрация.*
    
    **Лучше использовать `ngrok` (стабильнее):**
    1. Зарегистрируйтесь на ngrok.com (бесплатно).
    2. Установите: `brew install ngrok/ngrok/ngrok` (или скачайте с сайта).
    3. Запустите: `ngrok http 5173`.
    4. Скопируйте ссылку `https://....ngrok-free.app`.

5.  Вставьте эту ссылку в `bot_config.json` и запустите настройку бота:
    ```bash
    node scripts/setup_bot.js
    ```

---

## Вариант 2: GitHub Pages (Стабильно) 🐙
Если вы уже используете GitHub. Игра будет работать всегда, бесплатно.

1.  **Подготовка**:
    В файле `vite.config.ts` нужно добавить базовый путь (имя вашего репозитория).
    ```ts
    export default defineConfig({
      plugins: [react(), tailwindcss()],
      base: '/RepoName/' // <--- Замените на имя вашего репозитория!
    })
    ```

2.  **Загрузка**:
    Залейте код на GitHub.

3.  **Деплой**:
    В терминале установите деплоер:
    ```bash
    npm install gh-pages --save-dev
    ```
    
    Добавьте в `package.json` в раздел `"scripts"`:
    ```json
    "predeploy": "npm run build",
    "deploy": "gh-pages -d dist"
    ```

    Запустите:
    ```bash
    npm run deploy
    ```

4.  Ваша ссылка будет: `https://ваш-ник.github.io/имя-репозитория`.
    Вставьте её в `bot_config.json` и запустите `node scripts/setup_bot.js`.

---

### Рекомендация
Для быстрой проверки прямо сейчас используйте **Вариант 1 (Ngrok)**. Это позволит вам увидеть игру в Телеграме через 2 минуты без настройки серверов.
