# 🐙 Как опубликовать игру на GitHub Pages

Это обеспечит надежный хостинг для вашей игры. Игра будет работать всегда, бесплатно и без вашего ноутбука.

## Шаг 1: Создание Репозитория
1.  Зайдите на [github.com/new](https://github.com/new).
2.  Придумайте название (например, `farm-defense`).
3.  Выберите **Public**.
4.  Никакие галочки (README и т.д.) ставить **НЕ НУЖНО**.
5.  Нажмите **Create repository**.

## Шаг 2: Настройка Проекта
1.  В папке игры откройте файл `vite.config.ts`.
2.  Найдите строку:
    ```ts
    base: '/REPO_NAME/',
    ```
3.  Замените `REPO_NAME` на название вашего репозитория (например, `farm-defense`):
    ```ts
    base: '/farm-defense/',
    ```

## Шаг 3: Загрузка Кода
Откройте терминал в папке игры (`cd Desktop/Game`) и выполните команды (копируйте по одной):

```bash
git remote add origin https://github.com/ВАШ_НИК/farm-defense.git
git push -u origin main
```
*(Ссылку `https://github...` возьмите со страницы созданного репозитория).*

## Шаг 4: Публикация
В том же терминале запустите:

```bash
npm run deploy
```

Ждите, пока не напишет `Published`.
Игра появится по ссылке: `https://ВАШ_НИК.github.io/farm-defense/`.

## Шаг 5: Подключение к Боту
1.  Скопируйте полученную ссылку (`https://...`).
2.  Вставьте её в `bot_config.json`.
3.  Запустите настройку:
    ```bash
    node scripts/setup_bot.js
    ```

Всё! Теперь игра работает автономно 24/7. 🌍
